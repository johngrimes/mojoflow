# Constitution template

This is the canonical template for a project constitution. Replace every
`[BRACKETED_TOKEN]` with concrete text. Remove any HTML comments before
writing the final output.

When embedding this into `CLAUDE.md`, demote every heading by one level so
that the top-level `## Constitution` heading in `CLAUDE.md` is the parent
of this content.
